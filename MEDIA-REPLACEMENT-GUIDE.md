## 🎥 Video Specifications

### Explorations & UI Work (6 videos)
- **Files:** `public/explorations/exploration-[1-6].mp4`
- **Recommended size:** 800x800px or 1000x1000px (square)
- **Duration:** 5-15 seconds
- **Format:** MP4 (H.264 codec)
- **Features:** Autoplay, muted, looping
- **Max file size:** 5-10MB each

## 💡 Tips

1. **Compress images** before uploading (use TinyPNG or similar)
2. **Optimize videos** for web (use HandBrake or online compressor)
3. **Test locally** after adding files to ensure they load properly
4. **Consistent quality** - try to keep similar resolution/quality across all media
5. **File names** must match exactly (case-sensitive on some systems)
